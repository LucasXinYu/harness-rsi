# November 1, 2026: what is evolving, and what actually transfers?

The living collection adds **20 papers** first posted October 25–29, reaching **305 papers and 11 resources**. Dataset **v0.3.0** adds **19 records and eight scoped observations**, reaching 132 records / 100 works / 32 signals. A conceptual video survey remains bibliography-only. Search covered October 24–November 1 with overlap; 96 additional keyword hits await screening. This is a reviewed batch, not an exhaustive census.

## Improving the improver

[Skill Infinity](https://arxiv.org/abs/2610.35434v1) makes its optimization procedure an editable skill and evaluates revisions through inner skill-optimization gains. [RuHarness](https://arxiv.org/abs/2610.36826v1) instead evolves the diagnostic criteria that guide harness edits while keeping the external task evaluator fixed. These are distinct improvement targets: an editable procedure versus adaptive diagnosis. Neither paper alone establishes indefinite capability growth.

[GEPA-Curator](https://arxiv.org/abs/2610.37651v1) revises the evidence presented to optimization through task selection and prior-success retrieval. [HEMO](https://arxiv.org/abs/2610.40023v1) searches executable decision modules for multi-objective optimization. Their comparison suggests recording the search policy and evidence-selection mechanism separately from the task harness being improved.

## Persistence has several meanings

[MemSteer](https://arxiv.org/abs/2610.39276v1) optimizes memory design; [KARMA](https://arxiv.org/abs/2610.39884v1) edits typed knowledge while executable code stays fixed. [AMIE](https://arxiv.org/abs/2610.34977v1) changes later access to existing memories, and [CALM](https://arxiv.org/abs/2610.38573v1) separates stored evidence from query-time eligibility. The latter two include trained auxiliary selectors. A persistent memory state is not by itself a rewritten optimizer.

[SkillCompiler](https://arxiv.org/abs/2610.39508v1) combines program assets and LLM reasoning; its disclosed development exposure to held-out failures qualifies test claims despite frozen test banks. [MultiEvoSkill](https://arxiv.org/abs/2610.34260v1) evolves typed procedural graphs; workflow node-F1 results must not be described as interactive environment success.

## Stronger transfer descriptions require specifying the artifact

[SceneEvolve](https://arxiv.org/abs/2610.37046v1) evaluates an unchanged evolved harness on another model and dataset. [RSIV-Harness](https://arxiv.org/abs/2610.35316v1) also tests unchanged model transfer, but one metric regresses and the main study has only one evolution round. MemSteer's frozen-design transfer is separate from target-history personalization. AMIE transfers a fixed selector, not memory-ID state. Independently optimizing several backbones answers a different question.

[EvoLife](https://arxiv.org/abs/2610.39446v1) tests memory-assisted navigation and revisits; privileged guide information and repeated tasks qualify attribution. [Continual Learning Exam](https://arxiv.org/abs/2610.33956v1) offers long task ladders, but changing feedback and retry budgets together does not isolate cross-task memory benefit. A matched reset control remains necessary for that claim.

## Domain expansion and counterevidence

[VEvo-Harness](https://arxiv.org/abs/2610.39158v1) studies rendered-image admission gates. [MolRSI](https://arxiv.org/abs/2610.39714v1) and [RecRSI](https://arxiv.org/abs/2610.39352v1) search workflows that train downstream scientific or recommender models. [CoHARL](https://arxiv.org/abs/2610.36469v1) trains the executor itself alongside harness search; none should be pooled under a blanket “no training” claim. The [video-generation survey](https://arxiv.org/abs/2610.40191v1) provides conceptual context rather than a new measured intervention.

[Masked Erosion](https://arxiv.org/abs/2610.38392v1) shows why task-success gates can overlook lost safeguard redundancy in controlled tests. Its model-swap results motivate tracking regressions as well as gains; planted deletion experiments do not estimate deployment prevalence.
