03 / READING THE COLLECTION

A map of the research,
with the boundaries kept visible.

What is included?

Persistent changes to agent workflows, tools, prompts, memory mechanisms, and improvement procedures are the focus. Related training, search, infrastructure, and evaluation work provide context. Inclusion does not establish that a method achieves recursive self-improvement.

What do the dates mean?

We use first arXiv submission dates where recorded, arXiv identifier months otherwise, and bibliographic publication dates as a fallback. Exact days are never invented. Year-only and undated records are excluded from monthly plots. The final month or quarter may be partial.

How does it stay current?

The bibliography and annotations generate every count and chart. Dated snapshots track collection changes from the initial import onward. The search cutoff is explicit; a recent update can include older omissions. This is a curated collection, not a census of the field.
